# Project Instructions

This is a premium agency website for SitesBrand.

## Strict Rules

- Do not change the original visual identity.
- Do not redesign sections unless explicitly asked.
- Preserve colors, typography, spacing, layout, gradients, glass effects, shadows, and overall theme.
- Only improve quality, responsiveness, performance, accessibility, SEO, animations, and code structure.
- Use the uploaded screenshots and exported HTML as visual reference.
- Any new page must follow the same theme and design language.
- Do not remove existing sections.
- Do not replace the logo unless a new official logo file is provided.
- Add the official logo in the header, footer, and hero hexagon area when provided.
- Keep animations smooth, premium, and lightweight.
- Avoid heavy 3D that hurts performance.
- Run build, lint, and visual checks before the final response.

## Deployment

- Target platform: Vercel.
- Source of truth: GitHub repository.
- Production domain will be connected after preview approval.
